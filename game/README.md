# 수도 탈환작전 — 플레이 가능한 MVP

제주 도심 전장에서 생존하면서 포탑과 방벽을 직접 배치해 군용 텐트 HQ를 지키는 오프라인 2D 탑다운 생존 게임입니다. 현재 버전은 플레이 가능한 프로토타입이며, 전체 아트·밸런스·장시간 성능 검증을 완료한 정식판은 아닙니다.

## 실행

Godot 4.7.2로 `project.godot`를 열고 `scenes/main.tscn`을 실행합니다. Web MVP는 Webdev Preview에서 실행할 수 있으며 프로젝트 검사는 `npm run check`입니다.

## 조작

- WASD 또는 방향키: 이동
- Tab: 자동 공격과 수동 공격 전환
- 수동 공격: 마우스로 조준하고 좌클릭을 유지해 사격
- 총기는 탄창 소진 시 자동 재장전합니다. 탄약과 현재 모드는 전투 HUD에 표시됩니다.
- Shift: 회피 대시
- Escape: 일시정지
- 게임 안의 건설 메뉴를 열어 포탑·건물·방벽을 선택하고 배치합니다.

캐릭터와 난이도를 고른 뒤 제주도 인트로를 넘기면 전투가 시작됩니다. 전투는 시간에 따라 진행되고, 건설 UI를 열어도 멈추지 않습니다. 새 게임 시작 시 HQ 군용 텐트 하나만 배치됩니다.

## 구현 상태와 한계

## 2026-11-21 — 1차 캐릭터·맵 그래픽 업데이트

서하린 저프레임 4방향 스프라이트 시트를 `scripts/reclaim/character_visual.gd`에 연결하고, 제주 도심 지면·장식 오브젝트를 `scripts/reclaim/jeju_map_art.gd`에 연결했습니다. 기존 전투·건설·저장 시스템은 교체하지 않았습니다. 제작 원본 PNG는 `assets/reclaim/characters/`와 `assets/reclaim/world/`에 있습니다.

실제 Web 렌더러 캡처에는 서하린, 도심 지면·오브젝트, HQ 텐트가 보입니다. **해당 캡처에 좀비가 없고, 서하린의 이동·조준 사격·좀비 피격 장면을 영상이나 캡처로 직접 입증하지 못했습니다.** M4/30발 재장전과 드론 데이터, 공격·대시·피격 애니메이션 연결은 보존했지만, 이 화면만으로 사용자 조작과 좀비 명중까지 완료했다고 주장하지 않습니다. 따라서 도심에서 이동하며 좀비를 공격하는 최종 수락 기준은 미확인입니다.

## 구현 상태와 한계

코드에는 4명 캐릭터, 5종 적, 3개 보스 단계, 7종 포탑, 건설·충돌·출입구 경로 검사, 증강, 저장/이어하기, 설정 및 결과 흐름이 연결돼 있습니다. 자동 스모크 테스트는 메뉴 부팅, HQ 단독 시작, 유효·무효 배치, 포탑 제한, 공격, 시간 단계 진행과 일시정지를 검증합니다.

이번 범위에서 새로 적용된 그래픽은 서하린과 제주 도심 지면·장식입니다. **좀비·기타 캐릭터·건물·포탑의 완성 스프라이트, 5종 적의 구분된 아트/공격 모션은 이번에 구현하지 않았고 일부는 임시 도형/픽셀풍 표현입니다.** 자동 검사는 실제 조작의 이동·사격 영상 증빙을 대신하지 않습니다. 일부 캐릭터 고유 공격, 장시간 수백 적 성능, 1~100단계 전수 밸런스와 전체 시각 에셋은 후속 작업입니다. 모든 세부 수치는 테스트 전 임시 밸런스입니다.

이 프로젝트는 요청된 범위에 따라 온라인 기능·로그인·결제를 포함하지 않습니다. 참고 자료와 승인 시안은 `references/`에 보존하며 완성 에셋으로 재사용하지 않습니다.
