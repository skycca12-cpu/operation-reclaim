# 수도 탈환작전 — 구현 현황

기준: 사용자가 제공한 `수도탈환작전.zip`의 `01_최신_확정명세.md`와 `기존_개발자료_v03/03_개발지시/MVP_구현명세.md`, 2026-11-21 승인된 Game Blueprint. 수치·능력 중 임시인 것은 출시 밸런스 확정으로 취급하지 않는다.

## 0. 2026-11-21 1차 캐릭터·맵 업데이트
- [x] 서하린용 4방향 저프레임 스프라이트 시트를 만들고 캐릭터 렌더러에 연결했다. 실제 Web 화면에서 플레이어 스프라이트가 표시된다.
- [x] 반복 지면 타일 및 분리형 제주 도심 장식 오브젝트를 맵 렌더러에 연결했다. 실제 Web 화면에서 지면·오브젝트와 기존 HQ 텐트를 확인했다.
- [x] 신규 PNG를 asset registry에 등록하고 캐릭터·제주 도심 목적 그룹으로 분류했다. 승인 시안은 게임 배경에 쓰지 않았다.
- [ ] 실제 조작으로 서하린의 이동·대시·공격 애니메이션 및 좀비 피격을 검증한다. 저장된 캡처에는 좀비가 없어 사용자 명시 수락 기준은 미확인이다.
- [ ] 좀비 아트·5종 구분 애니메이션, 건물·포탑 최종 픽셀아트는 미완료이며 이번 범위에서 추가 구현하지 않았다.

## 1. 메뉴·출격 선택과 첫 전투
- [ ] 게임 흐름은 메인 메뉴(게임 시작/이어하기/설정/종료) → 4명 중 캐릭터 한 명 선택 → 난이도 5종(쉬움/보통/어려움/매우 어려움/지옥) 선택 → 제주도 첫 지역 출격 → 결과/재시작/메뉴로 구성한다.
- [ ] 4명은 강태준(산탄총+방패), 윤시혁(돌격소총), 서하린(M4 계열 30발 소총과 선택형 드론), 한유진(전기톱 지속 절단·과열, 공병/포탑 특화)이다. 한 판에는 선택 캐릭터 하나만 직접 조작하며 나머지 세 명은 동료·지원 인력으로 나오지 않는다.
- [ ] 제주도 출격 소개는 헬기에서 점령 도시를 조망하는 정지 이미지 3장과 페이드/자막으로 구현할 수 있고 건너뛸 수 있다. 인게임 첫 프레임에는 헬기가 없고 초기 기지는 군용 텐트 하나뿐이다.
- [ ] 난이도 배율은 제공된 `difficulty_mvp.json`의 HP/공격/스폰 임시값을 사용한다. 보통은 영구 강화 없이도 이길 수 있는 목표이며 실측 전 승률을 확정하지 않는다.

## 2. 생존 전투·적·단계 진행
- [ ] 플레이어는 WASD 직접 이동, 자동 기본 공격, 마우스 수동 조준, 회피/대시를 사용한다. 공격·대시·메뉴 키는 설정에서 재지정할 수 있게 설계한다.
- [ ] 카메라는 플레이어를 추적하며, 전투는 고정 화면 타워디펜스가 아닌 개방형 도심 전장에서 이뤄진다. 초기 월드는 한 화면 가로·세로의 각각 약 2배 이상 이동 가능하도록 하고 화면 가장자리의 연속 벽으로 이동을 막아 보이게 하지 않는다.
- [ ] 적은 일반(근접 추적), 질주(빠른 근접 추적), 자폭(접근 후 예고 폭발), 독액 투사(원거리 투사체), 괴력(바위 투척) 5종이다. 단계 1/10/20/25/35부터 해당 유형을 도입한다.
- [ ] 단계는 적 전멸을 기다리지 않고 시간으로 자동 진행하며 1~100단계를 지원한다. 보스는 40단계 방어형, 80단계 철거형, 100단계 군체형 패턴을 갖고 마지막 승리/패배/결과 흐름으로 끝난다.
- [ ] 화면 밖 원거리 공격은 공격 방향 경고, 착탄 표시와 회피 시간을 제공하고 즉발 피격을 피한다. 플레이어가 멀리 있어도 HQ 공격과 기지 방어의 상태는 유지한다.
- [ ] 일반 적 동시 활성 목표는 300~450마리이며 성능 유지가 우선이다. 풀링, 효과 상한, 거리별 단순 업데이트와 30/60 FPS 측정은 구현 범위에 따라 검증한다.

## 3. 실시간 수동 기지 건설·방어
- [ ] 중앙 건설구역은 7×7칸이며 경계/격자는 건설 모드에만 표시한다. 처음부터 놓이는 것은 HQ 군용 텐트 1개뿐이며 포탑·벽·동료·헬기를 자동 생성하지 않는다.
- [ ] 건설/강화 메뉴와 배치 중에도 시간·좀비·전투는 멈추지 않는다. 플레이어가 직접 건설·강화·철거한다. 설치 전 좌표·충돌·비용·점유·슬롯을 검사하며 실패 이유를 보여 준다.
- [ ] HQ·의료·보급·정비제작·연구·초소 일반 건물은 종류별 최대 1개, 2×1칸 이내이며 강화 후에도 점유 면적이 유지된다. HQ 파괴는 즉시 패배다.
- [ ] 기본 자동/균형, 중기관총/연사, 로켓/범위폭발, 전기/연쇄, 화염/지속광역, 냉각/감속, 수리 포탑의 7종을 지원한다. 각 1×1칸이며 레벨 1~5 데이터 구조를 두고, 총 포탑 제한은 일반 캐릭터 6기·한유진 8기다. 수리 포탑도 총 제한에 포함한다(명세의 초기 가정).
- [ ] 강화 비용, HP, 파괴, 수리 및 철거 후 슬롯 반환을 처리한다. 캐릭터 중 포탑 외형을 조정하더라도 크기·점유는 고정한다.
- [ ] 방벽은 지상 1칸 단위다. 동·서·남·북 각각 최소 1칸의 영구 입구를 유지하며 그 입구는 벽으로 막지 않고 플레이어·좀비가 통과한다. 기지 완전 봉쇄, 벽 위 적층, 계단, 벽 위 포탑, 고저차 충돌은 하지 않는다.
- [ ] 실제 7×7 점유에서 일반 건물 6종×2칸과 포탑 8칸의 최악 점유를 감안하고, 통로·출입구 및 플레이어 탈출 경로를 확인한다.

## 4. 전투 재화·증강·영구 성장
- [ ] 건설/보급용 전투 재화와 메인 메뉴 영구 강화용 작전 훈장은 분리한다. 작전 훈장은 특수 좀비·보스·업적으로 지급한다.
- [ ] 한 판 최대 15번 증강을 선택하고 매번 3장 중 1장을 고른다. 무료 리롤은 1회다. 증강 공용 30종+캐릭터별 5종(총 50종) 데이터의 확장 경로를 보존한다.
- [ ] 등급 확률은 회색 45%, 초록 30%, 파랑 15%, 보라 8%, 빨강 2%다. 등급과 별 개수는 별개이고 5성 중복은 제거한다.
- [ ] 영구 강화는 공격력·체력·범위·이동·건설속도·건물HP·재장전·재화량의 8종, 각 5강으로 데이터화한다.
- [ ] 이전 자료의 밸런스 값은 참고/임시로 표기하고, 오래된 데이터가 최신 확정 사항을 덮어쓰지 않는다. 플레이 테스트 전 미확정 무기/보스/경제 수치를 정식 밸런스로 주장하지 않는다.

## 5. 저장·설정·결과
- [ ] 저장/불러오기, 이어하기, 설정·키 바인딩, 전투 재화와 영구 재화, 패배/100단계 승리 결과를 게임에서 확인할 수 있다.
- [ ] 결과 화면은 캐릭터·난이도·진행 단계·처치/획득·성공/패배를 구분하고 재도전이나 메뉴 복귀 경로를 제공한다.

## 6. 시각 방향·로딩·에셋
- [ ] 사용자가 제공한 인게임 고정 기준 이미지와 캐릭터/포탑 시안은 카메라·분위기·UI·실루엣의 참고로 사용한다. 승인 시안은 완성 스프라이트가 아니며 통째로 캔버스 배경이나 실제 게임 스프라이트로 사용하지 않는다.
- [ ] 어두운 제주 도심 픽셀아트, 제주 색감·간판·해안 인트로와 가독성 있는 HUD를 지향한다. 전투는 넓고 평평한 공터/도로·골목을 이용하고 건물·차량은 주로 외곽 장식으로 둔다.
- [ ] 여섯 일반 건물, 7종 포탑×5레벨의 35 외형 상태에 확장 가능한 구조를 둔다. 실제 공격 모션은 각 포탑 역할에 맞는 조준/발사/폭발·연쇄/분사/감속/복구 피드백이며 효과는 본체와 분리한다.
- [ ] 게임 안에 타이틀·도움말·HUD 텍스트를 라이브 텍스트로 표시하고, 새 게임 기본 언어는 한국어 단일 언어다. 게임별 로딩 화면은 단색 배경, 수도 탈환작전 타이틀, 실제/불명확할 때 불확정 진행 표시, 읽을 수 있는 상태와 재시도 동작을 갖는다.
- [ ] 외부 유료 에셋이나 출처가 불명확한 소스는 사용하지 않는다. 임시 도형/에셋과 실제 제작 상태를 분리해서 알린다.

## 7. 전달 경계
- [x] 최초 전달은 바로 실행해 조작할 수 있는 플레이 가능한 MVP여야 하며, 화면 그림만으로 완료 처리하지 않는다.
- [ ] 프로젝트 소스, 실행 방법, 실제 구현된 기능, 임시 에셋/수치, 미구현·후속 항목을 전달한다. Windows 설치 파일, 전체 캐릭터/적/건설물 아트, 100단계 전 구간 밸런스, 수백 적 장시간 성능 결과는 근거가 없으면 완료로 표시하지 않는다.
- [x] 게임은 기본 데스크톱 키보드/마우스용이다. 온라인, 로그인, 결제는 요청 범위에 없다.
