# 제주도 개발 단계와 검수

## 0. 프로젝트 부팅
- [ ] PC 실행, 로딩→메뉴→캐릭터 선택→출격 3컷→맵 진입 연결
- [ ] 선택한 캐릭터 한 명만 스폰, 남성 캐릭터 수염 없음, 승인 외형 유지

## 1. 핵심 전투 수직 슬라이스 (1~10단계)
- [ ] 카메라가 캐릭터 추적, 4방향으로 시야 밖 이동 가능
- [ ] WASD 이동, 자동 공격, 수동 조준, 회피/대시
- [ ] 초기 HQ 텐트만 존재, 좀비 사방 등장, 시간 기반 단계 증가
- [ ] 좀비 50/150/300마리 성능 기록

## 2. 건설/포탑
- [ ] 7×7 설치 격자 및 2×1 건물 점유 검사
- [ ] 포탑 7종, 각 1×1, 일반 6/한유진 8 총합 제한
- [ ] 포탑 Lv.1~5 외형 차이와 자동 공격/수리 이펙트
- [ ] 4방향 출입구 유지, 벽으로 완전 봉쇄 불가
- [ ] 건설 메뉴 열어도 전투 지속, 기지 파괴 시 패배

## 3. 특수 적과 기지 방어
- [ ] 질주/자폭/독액/바위 투척 구현
- [ ] 화면 밖 투척 공격에 방향 경고와 회피 가능한 착탄 예고
- [ ] 플레이어 원거리 이동 중에도 기지 전투 유지

## 4. 제주도 100단계
- [ ] 시간 기반 1~100 자동 진행, 40/80/100 보스
- [ ] 난이도 5종, 재화/증강/영구 강화 연결
- [ ] 승리·패배·저장·불러오기·설정·결과 화면

## 5. 통합 검수
- [ ] 완성 기지에서도 캐릭터 통행 가능, 맵 동서남북 탐색 가능
- [ ] 모든 이미지의 스타일·크기·시점 일치, 게임용 에셋 분리
- [ ] 30/60 FPS 및 최대 활성 좀비 수 측정, 저사양 최적화 기록
- [ ] 소스, 빌드, 에셋, 실행 가이드, 미구현 목록 제출

**주의:** 인게임 고정 시안은 분위기 기준. 실제 첫 시작에 시안처럼 완성 기지/포탑 6개를 미리 설치하면 실패.
