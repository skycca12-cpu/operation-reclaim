# 최신 확정명세 — 2026-11-21

## 1. 장르와 맵 (최우선)
- **뱀파이어 서바이버류 이동·대량 전투가 중심**, 작은 기지 건설/방어를 결합. 고정 화면 타워디펜스로 만들지 말 것.
- 도심형 공통 지형. 제주도는 제주 특유의 분위기/색감/간판/해안 인트로로 구별. 실제 전투 지형은 넓고 평평한 개방형 공터, 도로와 골목으로 이동 연결.
- **플레이어 추적 카메라**. 중앙 기지에 화면을 고정하지 않는다. 현재 보이는 화면의 가로·세로 각각 약 2배 이상의 실제 이동 가능 영역을 초기 기준으로 잡는다(정확한 월드 단위는 프로토타입에서 확정). 화면 끝에 건물 벽을 연속 배치해 이동 불가처럼 보이게 하지 말 것.
- 도심 건물/차량은 주로 외곽 장식으로, 동서남북 이동 통로를 막지 않는다. 실제 충돌체가 있는 경우 우회 동선 확보. 전투 공터의 장애물은 최소화.
- 좀비는 화면 바깥의 유효한 위치에서 사방으로 등장하고, 플레이어를 쫓거나 기지를 공격. 원거리 돌 투척/독액 공격도 화면 밖에서 가능하나 **방향 경고·착탄 예고·회피 시간** 제공. 화면 밖 기지 전투는 시뮬레이션 유지하되 최적화.

## 2. 기지/건설
- 중앙 **7×7 = 49칸** 건설 구역, 실제 플레이 시 경계/격자는 건설 모드에서만 표시.
- 초기 상태: **작은 지휘본부 군용 텐트 하나 + 선택 캐릭터 한 명**, 헬기/동료/포탑/방벽/지원시설 미배치.
- 지휘본부·의료·보급·정비제작·연구·초소 등 일반 건물은 종류별 최대 1개, **각 2×1칸**. 초소의 실제 기능은 기존 문서와 통합 확인 필요. 외형과 충돌 모두 2×1 이내, 강화 후에도 면적 불변.
- 포탑 7종, 모두 **1×1칸**. 일반 캐릭터 **총합 6개**, 한유진 **총합 8개**. 파괴/철거되면 설치 슬롯 반환. 수리 포탑도 7종 총합 제한에 포함하는 것으로 **초기 구현 가정**(밸런스 검증 후 변경 가능).
- 방벽은 지상 1칸 단위 배치. **동·서·남·북 각 방향에 최소 1칸의 영구 개방 입구** 유지. 해당 입구에는 벽을 지을 수 없고 플레이어와 좀비 모두 통행 가능. 방벽으로 완전 봉쇄 금지. 벽 위 적층, 계단, 벽 위 포탑, 높이별 충돌 구현은 **취소**.
- 건설 중 시간·좀비·전투 **정지 금지**. 설치 전 유효 위치, 비용, 점유, 출입구, 이동 경로 검사. 건설 및 업그레이드는 플레이어 직접 조작. 지휘본부 파괴 즉시 패배.
- **공간 적합성 주의:** 건물 6종×2칸=12칸 + 포탑 8칸=20칸, 잔여 29칸에서 통로·방벽을 설계해야 한다. 실제 7×7 점유 맵으로 자동 검증할 것. 방벽 완전 폐쇄 방지 및 캐릭터 탈출 경로 검증 필수.

## 3. 포탑 7종 및 업그레이드
- 기본 자동포탑(균형), 중기관총(연사), 로켓(범위 폭발), 전기(연쇄), 화염(지속 광역), 냉각(감속), 수리(건물/방벽 회복).
- 군용 **삼각 지지대 + 긴 포신** 참고. 귀여운 둥근 로봇형으로 변경하지 말 것. 동일 시점·픽셀 비율·1×1 점유 유지.
- 각 Lv.1~5 **총 35개 외형 상태**. 기본: 방열판/조준 센서, 중기관총: 탄약통/총열, 로켓: 발사관, 전기: 코일/축전기, 화염: 노즐/연료통, 냉각: 냉매/결빙장치, 수리: 로봇팔/드론 순으로 강화. 크기는 고정.
- 공격 모션: 기본(조준→섬광→반동), 중기관총(회전→연사→탄피), 로켓(조준→발사→폭발), 전기(충전→연쇄), 화염(점화→분사), 냉각(충전→분사→감속), 수리(탐색→빔→복구). 애니메이션은 2~4프레임 재사용, 효과는 분리.
- 한유진은 포탑 +2개 및 성능 강화. 정확한 성능 보너스는 **임시 수치**로 시작해 플레이테스트로 조정. HQ 강화 패시브는 없음.

## 4. 캐릭터/전투/진행
- 4명 중 1명만 출격; 나머지 3명은 동료/기지 지원 인력으로 나오지 않음.
- 강태준 산탄총+방패, 윤시혁 돌격소총, 서하린 M4 계열 30발+선택 드론, **한유진 전기톱 지속 절단형** (근접에서 회전시키며 지속 피해, 공병/포탑 특화). 한유진 네일건/LMG 관련 과거 명세 폐기.
- 이동 직접 조작, 자동 기본 공격 + 마우스 수동 조준, 회피/대시. 키 재지정 지원.
- 적 5종: 일반/질주/자폭/독액 투사/괴력 바위 투척. 보스는 단계 40/80/100, 100단계 시간 자동 진행. 난이도 5종. 밸런스는 이전 데이터의 임시값을 사용하고 실측 후 수정.
- 화면 밖 투척 공격: 공격 주체가 보이지 않아도 방향 경고와 착탄 표시 제공, 불합리한 즉발 피격 금지.

## 5. 화면 흐름/아트 고정
- 실행 → 로딩 → 승인된 메인 메뉴 → 캐릭터 선택 → 제주도 출격 정지화면 연출(헬기에서 점령 도시 조망 → 착륙/하차 → 신속 진지 구축) → 게임 시작.
- 인트로는 정지 이미지 3장 + 페이드/자막으로 저비용 구현, 스킵 가능. **인게임 첫 프레임에 헬기 없음**, 군용 텐트만 존재.
- `05_승인참고이미지/인게임_고정기준.png`를 전투 분위기/UI/카메라 시각 기준으로 사용하되 이미지 속 완성된 기지·포탑·퀘스트·수치·레벨은 **시각적 예시**이며 실제 시작 상태가 아니다.
- 인게임 화면을 포탑 제작 때마다 새로 생성하거나 임의 변경 금지. 포탑은 별도 스프라이트/효과 레이어로 제작 후 삽입.
- 컨셉 시트는 완성된 게임용 투명 스프라이트가 아니다. 실제 PNG 프레임, 정렬, 피벗, 충돌 크기, 애니메이션 데이터 검수 필요.

## 6. 초보 개발에서 놓치기 쉬운 필수 사항
- 실시간 건설 중 사망/피격, 업그레이드 중 파괴, 포탑 철거 후 슬롯 반환, 비용 부족, 설치 충돌, 사방 출입구 봉쇄, 플레이어 기지 안 갇힘 테스트.
- 플레이어가 멀리 가도 기지 공격과 포탑 전투 유지. 다만 화면 밖 모든 좀비를 풀 물리 계산하지 말고 저비용 시뮬레이션/거리 기반 업데이트.
- 좀비 오브젝트 풀링, 효과 상한, 수백 마리 동시 테스트, 메모리 누수, 프레임 저하 기록.
- 자동 저장/불러오기, 설정·키 바인딩, 난이도 선택, 패배/승리 결과, 미완성 상태 표시, 라이선스 출처 기록.
- 구현 불가능한 기능은 조용히 삭제하지 말고 미구현/대안/예상 비용을 보고할 것.
