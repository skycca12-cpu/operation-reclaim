# MVP 구현 명세 (우선순위 순)

## 1. 게임 루프
메인 메뉴(게임 시작/이어하기/설정/종료) → 캐릭터 4명 중 1명 선택 → 난이도 5종 선택 → 첫 지역 진입 → 100단계 자동 시간 진행 → 보스 40·80·100 → 승리/패배 → 결과/영구 성장. 각 판은 선택한 캐릭터 1명만 직접 조작하며 다른 3명은 지원 인력이 아님. 최초 맵은 사각형, 중앙 원형 건설 가능 구역, **중앙 HQ 텐트 하나만 배치**. 벽/포탑/시설 자동 생성 금지.

## 2. 조작과 전투
WASD 이동, 자동 공격, 마우스 수동 조준 허용, 회피/대시. 스킬·조작 키는 설정에서 재지정 가능한 구조. 건설 메뉴/배치 중에도 좀비 공격과 시간 진행이 멈추지 않음. 일반 좀비 대량 학살 쾌감 + 특수 적의 위협을 병행. 1차 목표 동시 활성 300~450마리; 오브젝트 풀링, 거리별 단순화, 성능 측정 필수. 숫자보다 실제 프레임 유지 우선.

## 3. 플레이어
강태준(산탄총/방패), 윤시혁(돌격소총), 서하린(M4 계열 30발 돌격소총+선택 드론), 한유진(공병/시설 강화). 서하린의 이전 권총 수치는 폐기. 한유진 승인 그림에는 경기관총이 있지만 과거 수치 파일은 네일건이므로 전투 무기 최종 수치는 미확정으로 처리하고 디자인 승인 외형을 우선. 캐릭터별 기본 이동·공격·대기만 필수; 피격은 깜빡임, 사망은 간단한 전환으로 시작 가능.

## 4. 적/보스
기본 적은 04_데이터_최신/enemies_mvp.json의 5종만. 40/80/100 보스는 각각 방어형/철거형/군체형 패턴을 **간단한 형태**로 구현. 비행/지중 적은 후속 개발. 보스는 일반 적과 다른 체력·피격 규칙 및 경고 연출 필요. 자폭은 예고 후 폭발, 독액은 투사체, 괴력은 바위 투척.

## 5. 건설
지휘본부/방벽/포탑 우선. 중앙 원형 구역 내 격자 스냅 배치, 충돌 검사, 비용 차감, 수동 업그레이드, 철거, HP, 파괴 처리. 지휘본부 HP 0 즉시 패배. 각 시설 5티어×티어별 5강 확장 구조를 데이터로 유지하되 **MVP에는 우선 기본 티어와 실제 업그레이드 루프**를 작동시키고 이후 아트 교체. HQ 1티어는 군용 텐트, 방벽 1티어는 모래주머니. 방벽 위 포탑/고저차는 후속 단계의 2.5D 레이어로 확장 가능하게 설계. 기지 건물은 플레이어가 직접 배치/강화하고 자동 교체하지 않음.

## 6. 경제/증강/영구 성장
전투 재화는 건설·보급용. 별도 '작전 훈장'은 특수 좀비/보스/업적으로 획득하고 메인 메뉴의 영구 강화에 사용. 공격력/체력/범위/이동/건설속도/건물HP/재장전/재화량 5강 데이터화. 공용30+캐릭터별5종(총50종) 증강을 기존 CSV/JSON 참조로 구현. 한 판 15회 선택, 3개 카드 중 1개 선택, 무료 리롤 1회, 5성 중복 제거, 확률 회색45/초록30/파랑15/보라8/빨강2. 증강 등급과 별 개수는 별개. 02_밸런스_참고의 오래된 데이터는 최신 확정 사항과 충돌 시 수정하지 않고 '참고'로만 사용.

## 7. 난이도/진행
쉬움/보통/어려움/매우 어려움/지옥. 초기 배율은 difficulty_mvp.json. 보통은 영구 강화 없이도 클리어 가능한 목표. 어려움부터 60단계 위기, 지옥은 매우 높은 난도 허용. 단계는 적 전멸 대기가 아니라 시간으로 자동 증가. 1~100단계 지역 하나를 우선 구현. 실제 밸런스는 플레이 테스트로 수정. 압박 시뮬레이션은 실측 승률이 아님.

## 8. 그래픽/애니메이션
01_승인디자인 이미지는 승인된 **컨셉 시트**이지 프레임별 게임 에셋이 아님. 동일한 SD 픽셀아트 비율/팔레트/시점으로 실제 사용 가능한 투명 PNG를 별도 제작. 스프라이트 시트 프레임 크기·피벗·FPS·방향을 JSON으로 명시. 1차 애니메이션은 대기(2프레임), 이동(4프레임), 공격(3프레임) 정도를 목표로 하되 불가능하면 간단한 2프레임으로 대체 가능. 최소 기능 검증 우선. 건물은 정적 스프라이트+단순 발사/피격 이펙트부터.

## 9. 실행/검수
개발 환경·엔진은 Manus가 구현 가능성에 따라 선택하되 PC에서 실행 가능하고 소스와 에셋의 재사용이 쉬워야 함. 저장/불러오기, 설정, 전투 재화와 영구 재화 분리, UI 가독성, 한글 텍스트, 30/60 FPS 측정. 외부 유료 에셋이나 라이선스 불명 소스 사용 금지. 완료 보고 시 실제 작동하는 것/미구현/임시 에셋을 분리해서 기록.
